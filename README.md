## Android beta testing

Share https://teddytoymatch.com/beta/ for the Teddy Dreams Android test (package `com.tendonlife.teddybear`). The page uses the same general Google Group, `alpha-android-testers@googlegroups.com`, as other Android games, but only includes Teddy Dreams enrollment and installation links. No email addresses are collected by the site.

Before promoting the page, confirm the exact group and testing URL in the game's Google Play Console closed testing track, preserve existing tester eligibility, and verify enrollment with a non-owner account. The site's existing static hosting configuration serves `beta/index.html` at `/beta/`; verify public deployment after merging. Run `python3 tests/test_beta.py` to check the HTML links, local assets, and enrollment instructions.
